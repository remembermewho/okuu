# Полный ручной прогон Окуу — от нуля до финала

План для тестировщика (Claude Desktop). Цель — пройти систему как живые пользователи и **сверить каждую сумму** с ожидаемой. Ожидаемые значения посчитаны заранее; если система показывает другое — это находка.

Важно про даты: расчёты ниже верны, если **сегодня не 1-е число месяца**. «Сегодня» — по Бишкеку (UTC+6).

---

## Правила (обязательно)

1. Работать только с: http://localhost:5173 (приложение), http://localhost:5180 (лендинг), http://localhost:8080 (API), локальной базой в Docker.
2. Telegram: **только чат с тестовым ботом okuu_dev_bot. Не открывать другие чаты, ничего никому не писать, не менять настройки Telegram, не вступать в группы. Если Telegram открылся на другом чате — сразу вернуться в чат бота.
3. Код не менять, git-команды не выполнять, ничего не коммитить.
4. Разрешённые команды в PowerShell (в папке `okuu`):
   - `npm run dev` (запуск всего), Ctrl+C (остановка)
   - `docker compose down -v` (только в разделе 0)
   - `cd backend` + `go run ./cmd/server admin registration-link --note=...`, `admin grant --phone=...`, `billing run --center=... --date=...`, `demo seed ...`, `demo reset`
   - SQL только через: `docker exec -i okuu-db psql -U okuu -d okuu -c "<запрос>"` и только запросы из этого плана (плюс SELECT для проверки).
   - Ничего другого не запускать.
5. Пароли и телефоны — только тестовые из таблицы ниже.
6. Если шаг не получается после 3 попыток — записать находку и идти дальше.
7. Результаты — в файл `docs/test-report.md` (формат в конце). Писать в него по ходу, после каждого раздела.
