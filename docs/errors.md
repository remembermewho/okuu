# Коды ошибок API

Любая ошибка API — один формат:

```json
{"error": {"code": "validation", "message": "ФИО — обязательное поле", "field": "full_name"}}
```

- `code` — машинный код: по нему фронтенд решает, что делать. Список ниже полный, новые коды
  добавляются сюда и в [openapi.yaml](openapi.yaml).
- `message` — готовый текст для человека (по-русски); показывать как есть, если нет своего.
- `field` — только у `validation`: поле запроса (`full_name`, `parent.phone`, `Idempotency-Key`,
  у импорта — `file`), чтобы подсветить его в форме.

Какие коды бывают у какого эндпоинта — в описании ответов в [openapi.yaml](openapi.yaml).

## Общие (любой маршрут)

| code | HTTP | Когда | Что делать на фронтенде |
| --- | --- | --- | --- |
| `validation` | 400 | Неверное значение поля: пустое, не тот формат, вне диапазона. Поле — в `field` | Подсветить поле, показать `message` |
| `validation` | 422 | Значение допустимо само по себе, но не подходит по смыслу: группа из архива, дата занятия в будущем, ученик не записан в группу | Как 400 |
| `bad_request` | 400 | Тело не JSON, в нём неизвестные поля или несколько объектов | Ошибка фронтенда — в лог/Sentry |
| `unauthorized` | 401 | Нет сессии или она истекла (30 дней без входа) | На экран входа |
| `bad_origin` | 403 | У изменяющего запроса (`POST`/`PUT`/`PATCH`/`DELETE`) заголовок `Origin` не равен адресу фронтенда (защита от CSRF) | Ошибка конфигурации — в лог |
| `forbidden` | 403 | Роль не подходит (преподаватель открыл деньги, админ — настройки центра) | «Недостаточно прав», спрятать кнопку |
| `center_pending` | 403 | Любой маршрут `/c/{centerId}`: заявка центра ещё не одобрена суперадмином (режим `approval`) | Экран «Заявка на рассмотрении»; обновить `/me` |
| `center_blocked` | 403 | Любой маршрут `/c/{centerId}`: доступ к центру приостановлен суперадмином | Экран «Доступ приостановлен, свяжитесь с поддержкой»; обновить `/me` |
| `not_found` | 404 | Нет такой сущности в этом центре, некорректный id в пути, центр не ваш, ссылка оплаты неизвестна или истекла | «Не найдено» |
| `method_not_allowed` | 405 | Метод не поддерживается маршрутом | Ошибка фронтенда |
| `too_large` | 413 | Тело запроса больше 1 МБ (импорт — 6 МБ) | — |
| `internal` | 500 | Ошибка сервера. Подробности — в логе сервера по `X-Request-ID` | «Что-то пошло не так», предложить повторить; показать `X-Request-ID` для поддержки |

Чужой центр — всегда `404`, а не `403`: так не видно, существует ли он.

## Вход и приглашения сотрудников

| code | HTTP | Когда |
| --- | --- | --- |
| `phone_taken` | 409 | Регистрация: телефон уже зарегистрирован — предложить войти |
| `invalid_credentials` | 401 | Вход: неверный телефон или пароль (не уточняем, что именно) |
| `registration_closed` | 403 | Регистрация: режим `invite` (по умолчанию в prod), а `registration_token` нет — показать «Регистрация по приглашению» и WhatsApp поддержки |
| `registration_invalid` | 404 | Ссылка регистрации `/register/{токен}` использована, отозвана, просрочена (14 дней) или неизвестна |
| `too_many_attempts` | 429 | Вход: 5 неудачных попыток за 15 минут на телефон или IP. Через сколько повторить — заголовок `Retry-After` (секунды) |
| `invite_invalid` | 404 | Приглашение сотрудника не найдено, уже использовано, отозвано или просрочено |
| `login_required` | 409 | Принятие приглашения: телефон уже зарегистрирован — войти и принять снова |
| `already_member` | 409 | Принятие приглашения: вы уже сотрудник этого центра |

## Пароль и сброс

| code | HTTP | Когда |
| --- | --- | --- |
| `validation` | 400 | Смена пароля: неверный текущий (`field = current_password`) или новый не по правилам (`field = new_password`) |
| `too_many_attempts` | 429 | Смена пароля: 5 неверных текущих паролей за 15 минут (на пользователя или IP). `Retry-After` — секунды |
| `reset_not_allowed` | 409 | Владелец не может сбросить пароль этому сотруднику: тот работает ещё в другом центре или сам владелец. Сброс — через поддержку (`server user reset-link`) |
| `reset_invalid` | 404 | Ссылка сброса пароля неизвестна, просрочена (24 часа), заменена новой или уже использована — ответ одинаковый |

## Сотрудники, тарифы

| code | HTTP | Когда |
| --- | --- | --- |
| `owner_protected` | 409 | Владельца центра нельзя понизить или удалить |
| `teacher_has_groups` | 409 | Преподавателя нельзя удалить из центра, пока за ним есть активные группы — сначала назначить им другого |
| `tariff_in_use` | 409 | Тип тарифа (месячный ↔ абонемент) нельзя менять, когда на него записаны ученики |

## Ученики и записи в группы

| code | HTTP | Когда |
| --- | --- | --- |
| `parent_phone_taken` | 409 | Новый телефон родителя уже у другого родителя в этом центре |
| `already_enrolled` | 409 | У ученика уже есть активная запись в эту группу |
| `enrollment_ended` | 409 | Запись уже завершена (завершить или продлить нельзя) |
| `not_package` | 409 | Продлить можно только абонемент |
| `student_left` | 409 | Ученик ушёл: новые записи и продления — после смены статуса |
| `telegram_not_configured` | 409 | Приглашение родителя или «Напомнить»: Telegram-бот не настроен на сервере |
| `demo_center` | 409 | Приглашение родителя или «Напомнить» в демо-центре: родители вымышленные, сообщения не отправляются |

## Деньги

| code | HTTP | Когда |
| --- | --- | --- |
| `validation` (`field: Idempotency-Key`) | 400 | Нет заголовка `Idempotency-Key` у оплаты/возврата/поправки |
| `idempotency_mismatch` | 422 | Этот `Idempotency-Key` уже использован для операции с другими данными (повтор с теми же данными — `200` и та же операция) |
| `already_cancelled` | 409 | Операция уже отменена |
| `forbidden` | 403 | Оплату Finik отменяет только владелец (R15) |

## Посещаемость

| code | HTTP | Когда |
| --- | --- | --- |
| `lesson_exists` | 409 | У группы уже есть занятие в эту дату и время |
| `lesson_cancelled` | 409 | Отметки на отменённом занятии не ставятся |
| `forbidden` | 403 | Преподаватель меняет отметки только своих групп и только за последние 7 дней (R12) |

## Импорт

| code | HTTP | Когда |
| --- | --- | --- |
| `file_too_large` | 413 | Файл больше 5 МБ (`field: file`) — разбить на части |
| `import_already_committed` | 409 | Этот импорт уже подтверждён |
| `import_expired` | 410 | Превью хранится час — загрузить файл заново |

## Страница оплаты (`/api/v1/pay/{token}`)

| code | HTTP | Когда |
| --- | --- | --- |
| `not_found` | 404 | Ссылки нет или она истекла (24 часа) — ответ одинаковый; попросить новую ссылку в боте |
| `already_paid` | 409 | По ссылке уже заплатили |
| `too_many_requests` | 429 | Больше 30 запросов в минуту с одного IP; `Retry-After` |
| `provider_unavailable` | 502 | Платёжный сервис не создал платёж или онлайн-оплата ещё не подключена (Finik — заглушка) — повторить позже / оплатить по реквизитам |

## Панель суперадмина (`/api/v1/admin`)

| code | HTTP | Когда |
| --- | --- | --- |
| `not_found` | 404 | Нет такого центра или ссылки — и так же любому, кто не суперадмин (в том числе без входа): существование панели не раскрываем |
| `center_status_conflict` | 409 | Одобрить не заявку, заблокировать уже заблокированный, вернуть доступ незаблокированному — обновить карточку |
| `registration_link_closed` | 409 | Отозвать ссылку регистрации, которую уже использовали или отозвали |
| `no_owner` | 409 | Ссылка сброса пароля владельца: у центра нет владельца (ручная правка БД) |

## Вне `/api/v1` (не для фронтенда)

| code | HTTP | Где |
| --- | --- | --- |
| `db_unavailable` | 503 | `GET /healthz` — база недоступна |
| `busy` | 503 | `POST /webhooks/telegram/{secret}` — очередь апдейтов занята, Telegram повторит |
| `bad_signature` | 401 | `POST /webhooks/finik` — подпись уведомления не сошлась |
| `provider_unavailable` | 503 | `POST /webhooks/finik` — провайдер Finik ещё заглушка (TODO) |
| `bad_request` | 400 | `POST /webhooks/finik` — в уведомлении нет нужных данных |

`GET /readyz` отвечает не ошибкой, а списком проверок: `{"status": "not_ready", "checks": {"db": "ok", "migrations": "…", "scheduler": "…"}}` (503).
